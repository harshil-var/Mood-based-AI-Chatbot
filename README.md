# 🤖 Mood-Based AI Chatbot

A simple AI chatbot that changes its conversational style based on the selected mood. The chatbot can interact with users in **Angry, Funny, and Sad** moods, making conversations more dynamic and engaging.

## ✨ Features

* 💬 Interactive AI chatbot
* 😠 **Angry Mood** – responds in an angry/aggressive style
* 😂 **Funny Mood** – responds with humor and jokes
* 😢 **Sad Mood** – responds in a sad/emotional style
* 🎭 Mood-based response generation
* 🖥️ Simple and user-friendly interface

## 🛠️ Tech Stack

* **Python**
* **AI / NLP**
* **Streamlit** *(if you are using Streamlit)*
* **AI model: Mistral_AI / API: Hugging_Face **

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/mood-based-ai-chatbot.git
```

### 2. Navigate to the project

```bash
cd mood-based-ai-chatbot
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
streamlit run app.py
```
